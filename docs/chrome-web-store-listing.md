```
競馬データをワンクリックで整形コピーできる Chrome 拡張機能です。

【 v1.3.0 新機能】
- CSV ダウンロード機能追加（保存先フォルダを自由に指定可能）
- ファイル名を「日付_レース名.csv 」形式で自動生成
- BOM 付き UTF-8 出力で Excel 文字化けなし

【こんな方におすすめ】
- 競馬データを Excel や Google Sheets で分析したい方
- ChatGPT や Claude で競馬予想をしたい方
- 競馬ブログや SNS に出馬表・結果を貼りたい方
- netkeiba のデータを手作業でコピーするのが面倒な方
- Python やスクレイピングの知識がない方

【主な機能】
- ワンクリックでレースデータを整形コピー
- 3 つの出力フォーマット: Markdown / CSV / AI 分析プロンプト
- netkeiba.com 中央競馬（出馬表・レース結果）に対応
- netkeiba.com 地方競馬 NAR（出馬表・レース結果）に対応
- JRA 公式サイト（出馬表・レース結果）に対応

【使い方】
1. netkeiba.com（中央・地方）または JRA 公式の出馬表/レース結果ページを開く
2. 拡張機能のアイコンをクリック
3. フォーマットを選択（ Markdown / CSV / AI）
4. 「データ抽出」をクリック
5. 「クリップボードにコピー」で完了

【活用例】
- ChatGPT / Claude に貼り付けて AI 競馬予想
- Excel / Google Sheets に貼り付けてデータ分析
- ブログや note にきれいなテーブルとして掲載
- X (Twitter) や LINE で出馬表をシェア
- 自分用の競馬ノートに記録

【 Free プラン】
- Markdown テーブル出力（無料・無制限）
- 抽出履歴の保存（最大 10 件）

【 Pro プラン】
- CSV 出力（ Excel ・ Google Sheets 対応）
- AI 分析プロンプト自動生成（予想用・回顧用）※ Free プランは月 3 回まで

【プライバシー・安全性】
- DOM 読み取りのみ。データは外部送信されません
- サーバーとの通信は一切ありません
- ライセンス情報もローカル保存のみ

【対応サイト】
- netkeiba.com 中央競馬（出馬表・レース結果）
```

### Detailed Description

```
A Chrome extension that lets you copy formatted Japanese horse racing data in one click.

【 What's New in v1.3.0 】
- CSV download button added — choose your save folder directly
- Auto-generated filename: "date_race-name.csv"
- BOM-encoded UTF-8 for seamless Excel compatibility

【 Who is this for?】
- Anyone analyzing JRA races in Excel or Google Sheets
- ChatGPT or Claude users making horse racing predictions
- International fans following Japan Cup, Arima Kinen, and all JRA races
- Bloggers and content creators covering Japanese racing
- Anyone tired of manually copying race data from netkeiba.com

【 Features 】
- One-click formatted race data copy
- 3 output formats: Markdown / CSV / AI analysis prompt
- Supports netkeiba.com JRA central racing (race cards & results)
- Supports netkeiba.com NAR local racing (race cards & results)
- Supports JRA official site (race cards & results)

【 How to use 】
1. Open a race card or result page on netkeiba.com or JRA official site
2. Click the extension icon
3. Select your format (Markdown / CSV / AI)
4. Click "Data Extract"
5. Click "Copy to Clipboard"

【 Use cases 】
- Paste into ChatGPT / Claude for AI-powered race predictions
- Import into Excel / Google Sheets for data analysis
- Embed clean tables in your blog or social media
- Build your personal race notes and records

【 Free Plan 】
- Markdown table output (free, unlimited)
- Extraction history (up to 10 entries)

【 Pro Plan 】
- CSV export (Excel & Google Sheets compatible)
- AI analysis prompt auto-generation (prediction & review templates) *Free plan limited to 3 uses/month

【 Privacy & Safety 】
- DOM read-only. No data is sent externally
- Zero server communication
- License info stored locally only

【 Supported Sites 】
- netkeiba.com JRA central racing (race cards & results)
- netkeiba.com NAR local racing (race cards & results)
- JRA official site (race cards & results)
```
